# Book images

Put each book's info image here, named exactly as `import_books.py` prints on
run (e.g. `qulogim-senda-qizim.jpg`). The bot sends this image to a user when
the AI assistant recommends that book. The image should contain the book's
details — it IS the information the customer sees.

Filenames must match the `image` column in the `books` table.
